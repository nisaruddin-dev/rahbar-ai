Rahbar AI

Verified admission decision-support for Pakistani FSc students

Mid-Hackathon Submission Nisar Uddin September 2026
The Problem

Pakistani FSc students miss admission opportunities

  • Information is scattered across portals, PDFs, notices, and WhatsApp rumors
  • Many students don't know they can apply with FSc Part-I marks before their final result
  • Aggregate formulas differ by university — easy to miscalculate
  • Generic AI tools guess — they can't be trusted with critical deadlines

"The problem isn't lack of information. It's converting it into the right decision at the right time."

The Solution

Rahbar AI turns verified data into clear decisions

Architecture

How it's built

app.py Streamlit UI + Gemini call — orchestration only
engine.py Deterministic logic — never imports Streamlit
data/universities.py Verified university data registry
AI = Language. Rules = Decisions. Code = Calculations. Data = Truth.
The AI never calculates — it only explains
Every critical fact is traceable to a source
If Gemini fails, the deterministic output still renders
